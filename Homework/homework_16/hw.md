### Дай определение терминам:

1. **HTTP (расшифруй и объясни назначение)** – это прикладной протокол (HyperText Transfer Protocol — протокол передачи гипертекста), он нужен для передачи данных, для обмена информацией между клиентом и сервером. Так же он определяет формат запросов и ответов, методы, заголовки и тд.
2. **HTTPS — чем отличается от HTTP?**  
   HTTPS – надежнее чем HTTP. В HTTPS данные шифруются, гарантирует целостность данные, так же использует порт 443.
3. **Клиент-серверная модель** — это структура взаимодействия, где клиент отправляет запросы, а сервер обрабатывает их, а затем возвращает ответы.
4. **Идемпотентность** — это операция, при которой ее частое выполнение дает тот же результат, что и однократное.

### 2.1. Разбери запрос

**Дан HTTP-запрос:**
```http
POST /api/users HTTP/1.1
Host: example.com
Content-Type: application/json
Authorization: Bearer eyJhbGciOiJIUzI1NiIs...
Content-Length: 58

{"name": "Иван", "email": "ivan@mail.com"}
```

**Ответь на вопросы:**
1. *Какой метод используется?*  
   Используется метод POST (для создания нового ресурса)
2. *Какой путь (endpoint) запрашивается?*  
   Путь: `/api/users`
3. *Какая версия HTTP?*  
   HTTP/1.1
4. *Что означает заголовок Content-Type?*  
   Он говорит какой тип данных в запросе. У нас `application/json`, следовательно JSON
5. *Что означает заголовок Authorization?*  
   Заголовок, где клиент передает запрос серверу подтверждение, что он уже в сиситеме.  
   * `Bearer` – тип пропуска  
   * `eyJhbGciOiJIUzI1NiIs` - пропуск
6. *Где находится тело запроса?*  
   Тело находится в фигурных скобочках `{"name": "Иван", "email": "ivan@mail.com"}`  
   Длина тела равна 58 байт (записано в Content-Length)

**Дан HTTP-ответ:**
```http
HTTP/1.1 201 Created
Content-Type: application/json
Location: /api/users/42

{"id": 42, "name": "Иван", "email": "ivan@mail.com"}
```

**Ответь:**
1. *Что означает статус-код 201?*  
   Статус-код 201 говорит о том, что ресурс успешно создон.
2. *Зачем нужен заголовок Location?*  
   Заголовок для созданного ресурса в URL 
3. *Что находится в теле ответа?*  
   В теле находится `{"id": 42, "name": "Иван", "email": "ivan@mail.com"}`

### 2.3. Собери запрос сам

**Составь HTTP-запрос для:**

* **Получения списка всех товаров**
  ```http
  GET /api/product HTTP/1.1
  Host: example.com
  Accept: application/json
  ```

* **Создания нового товара с именем "Ноутбук" и ценой 50000**
  ```http
  POST /api/product HTTP/1.1
  Host: example.com
  Content-Type: application/json
  Content-Length: 43

  {"name": "Ноутбук", "price": 50000}
  ```

* **Удаления товара с id=7**
  ```http
  DELETE /api/product/7 HTTP/1.1
  Host: example.com
  ```

* **Обновления товара с id=3 (изменить цену на 45000)**
  ```http
  PATCH /api/product/3 HTTP/1.1
  Host: example.com
  Content-Type: application/json

  {"price": 45000}
  ```
