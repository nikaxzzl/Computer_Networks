# Компьютерные сети

Добро пожаловать на курс «Компьютерные сети»! Здесь вы разберётесь, как устроена сеть как среда работы приложений — от физического уровня и адресации до маршрутизации и разрешения имён, — и освоите практические навыки планирования и диагностики сетей.

## О курсе

Курс построен по принципу «от модели к практике»: сначала вы поймёте, как данные проходят по уровням сети, затем научитесь планировать адресное пространство и настраивать базовые сетевые сервисы, а в конце — диагностировать типичные проблемы. Все материалы и результаты практик ведутся в едином репозитории курса.

## Как устроена работа

- **Единый репозиторий.** Все материалы, заметки и результаты практик ведутся в одном репозитории курса.
- **Практикумы.** Расчёт подсетей и проверка конфигурации выполняются на реальных сценариях, а не на абстрактных примерах.

## Структура репозитория

Репозиторий организован по папкам, соответствующим разным типам работ:

- **`Material/`** — презентации и теоретические материалы к занятиям (файлы `.pptx`), а также вспомогательные файлы для практики (например, `nast3.pkt`).
- **`Homework/`** — выполненные домашние задания. Для каждого урока создаётся отдельная папка (`homework_07`, `homework_08` и т.д.), внутри которой находится файл `README.md` с отчётом.
- **`Praktika/`** — файлы практических работ, включая скриншоты выполнения заданий (например, `praktika_1.png`, `pracrika_2.png`).
- **`independent/`** — самостоятельные работы (например, файл `sm.md`).
- **`README.md`** (в корне) — главный файл с оглавлением курса: таблица всех уроков, даты, темы и краткое описание того, что было сделано.

Внутри папок с домашними заданиями обычно лежат:
1. **`README.md`** — отчёт с описанием задания и того, что было выполнено.
2. **Файлы работы** — документы `.md` с решением, изображения (`.png`), проекты симулятора (`.pkt`).
